# 聊天与卡片设计

小瑞采用一个持续对话。顶部保留小瑞的身份入口和「我的资料卡」，底部保留文字与单条语音切换，加号打开图片与电话等入口。短消息的气泡随内容收窄，长消息换行。查询和生成进度跟随对应消息，回复接在同一处。

说话和发消息可以同时进行。电话状态只在顶部通话条提示，用户发出的文字继续得到独立回复。语音优先讲此刻需要知道的一两件事，屏幕卡片保留名称、图片、费用及操作按钮。用户可以看卡，也可以请小瑞把选项念出来。[电话交互](phone-interaction.md)

## 卡片

每组卡片先说明用途，例如「选门店」「选一份套餐」或「确认订单」。餐品卡使用官方图片和价格字段，缺少数据时显示对应状态。卡片区分菜单参考价和含费总价，保留大字号价格和点击区域。选择与确认分开，确认时展示实际商品、数量、地址和金额。[生活服务](services.md)

## 角色与资料

桌面角色根据真实交互显示空闲、倾听、思考、播报、出行或用餐状态。窄屏优先保留消息和输入框，开启减少动态时保留静态姿态和图标。[角色状态](companion-states.md)

重要资料通过「我的资料卡」查看、修改、逐项核对和保存。本人或家人确认的信息用于后续办事，聊天中可另行维护普通偏好。[个人资料与记忆](memory.md)
