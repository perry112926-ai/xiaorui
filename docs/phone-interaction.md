# 电话与消息分开

2026-11-05：电话使用独立的通话标识，不再把实时通话当作逐条文字消息显示。

## 使用体验

- “＋”中的语音通话入口拨打电话；接通后主动问候，并一次问一个自然、必要的问题。
- 电话期间保留原版文字输入框，可同时发文字或图片消息；页面顶部显示灵动岛式“通话中”、时长、“我说完了”和挂断操作。通话过程只在灵动岛下方的小字中提示。
- 口头提问、口头回答及实时转录不生成聊天气泡。选餐、门店、定位和交易方案等真实卡片仍发到聊天区，并通过语音说明“我给您发了卡片，选好告诉我”。也可要求念出选项。
- 点击卡片产生的选择仍属于当前通话，后续答复以语音继续。手动输入的文字消息始终作为普通聊天展示和回复，不混入电话转录，也不打断正在播放的电话语音。交易确认仍使用原有受控方案，不因通话免除确认。
- 挂断后聊天中保留一条“语音通话＋时长”记录；记录刷新可恢复，重复结束不会产生重复记录。
- 移除输入框上方常驻的“小瑞在这里”状态面板。每条文字消息之后显示其自己的处理进度及逐步生成的回复，完成后原位置替换成正式答复，不留下重复进度条。普通消息与通话不会互相覆盖处理进度。
- 挂断立即停止收音和播报；已接收的后台操作不被当作撤销。迟到卡片可继续出现，迟到语音不自动播放，也不写成文字回答气泡。

## 实现与边界

通话开始／结束由本机后端记录，时长由服务端计算。刷新或服务重启后，上次通话结束，不自动重启麦克风。通话标识绑定当前本机浏览器会话；不能给已结束或其他会话的电话追加语音轮次。普通消息与电话消息不会拼成同一批次。

这是浏览器里的语音交互，不是接入微信或运营商电话。通话转录从聊天展示中分离；为了处理任务、保持上下文和核对操作，底层 Agent／本机处理记录仍可能保留相关文本。本轮不实现自动删除底层记录，也不保存可回放的整段通话录音。

## 验证

该专题初次验收时，235 项后端测试、42 项前端测试通过，TypeScript 与生产构建通过。覆盖包括通话所有权、结束幂等、刷新恢复、消息与电话隔离、真实卡片语音提示、挂断迟到回复隔离，以及通话期间打字、按消息归属更新进度及合并回复的位置。

8001 实际预览服务已验证首页及构建资源可访问，通话创建／结束接口可用，重复结束只保留一条可恢复的时长记录；该检查未调用模型或执行交易。

真人语音的识别、回声和连贯体验仍需实机试用，自动化测试不能代替真人通话验收。

## 当前语音链路与待验收项

普通停顿与普通问题提交后已移除固定承接语。正式入口沿用豆包 ASR、文本 Agent 与渐进 TTS。文字可先交付，播报随后更新。普通无句末标点和有句末标点的静默阈值分别是 1200 ms 和 900 ms，老人实际停顿和播放失败后的恢复仍需实测。

Pipecat 隔离验证覆盖十轮合成语音与双向 WebRTC，服务器首段 PCM 中位数为 1.55 秒。正式电话仍走现有链路，自动断句到浏览器出声及物理回声仍待实测。见[隔离验收](acceptance/pipecat-isolated-2026-11-06.json)。
