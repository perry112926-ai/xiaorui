# 电话与消息

1. 在输入框旁点「＋」和「语音通话」，授权麦克风。顶部通话条显示状态、时长、「我说完了」和挂断。
2. 通话时可以直接说话。小瑞在停顿后接话，用户再次开口可停止播报，也可点击「我说完了」提交本轮。底部输入框继续接收文字和图片，手动发送的消息按普通聊天显示。
3. 需要选餐、核对地点或确认方案时，小瑞发卡片到聊天，并在通话里说明如何选择。可以点卡片、口头说选项，或者请小瑞读出来。
4. 挂断后释放麦克风并停止播放，聊天保留一条带时长的通话记录。收到的业务卡片仍可查看，已提交操作可按卡片或官方订单状态核查。

通话发生在本机浏览器页面。口头对话和转录显示在通话区域，聊天只显示通话摘要、卡片和手动消息。用于任务处理的转录文本可能保存在底层会话记录中。[记忆与资料](memory.md)

麦克风不可用时，检查浏览器与 macOS 权限，或继续通过文字办事。每次通话由用户启动，刷新页面后可重新拨打。[语音配置](setup.md)
