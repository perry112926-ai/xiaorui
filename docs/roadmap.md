## 下一步优先级

当前语音专项：用户反馈反复“我在，您说”无法聊天，优先验证独立实时语音会话层，停止以固定短回应首音作为自然通话通过证据。选型、现状诊断与新验收目标见[实时电话架构调研](research/2026-11-05/realtime-feedback.md)。 2026-11-06已完成[Pipecat隔离验证](acceptance/pipecat-isolated-2026-11-06.json)：核心流水线、十轮合成语音、双向WebRTC与中文轮次模型可运行；首段服务器PCM中位数1.55秒，自动断句到浏览器播放与物理回声尚未验收，完整接入门槛未通过，正式电话入口未替换。

1. **真实办事闭环与 API**（当前优先）：先验证麦当劳聊天选店、选品、核价、确认卡片、支付入口与订单查询；同步逐项验证瑞幸和滴滴接口。真实交易按具体方案确认；瑞幸保留历史未知请求保护。范围和限制见[服务边界](services.md)。
2. **语音可用性**：在接口闭环后，真人连续两轮，验证插话、停顿、通话中打字、权限拒绝与挂断；减少等待并调整听感。
3. **持续任务与个人资料**：一个目标有稳定 ID，补充后可继续、修改和取消；资料卡刷新／重启后可用，重要资料需人工核对修改，普通偏好能纠正与忘记。
4. **真实提醒**：验证苹果提醒事项创建、查询、修改、取消和实际通知，说明 Mac 睡眠与服务退出条件。
5. **受控主动交流**：先做相关情境中的可拒绝提问和偏好确认，再做可暂停的时间触发与内容分享；抖音和作品来源分别验证。
6. **收口交付**：干净下载、配置凭据、一键启动，完成演示与验收记录。

## 理想综合演示

核对资料卡并保存家庭地址与偏好 → 刷新／重启后在同一聊天继续使用 → 规划出行与确认服务 → 设置真实提醒 → 按偏好推荐午餐 → 改需求并继续任务 → 花钱前核对确认 → 修改或忘记资料。主动内容分享作为后续扩展。
