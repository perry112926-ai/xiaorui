# 外部审查改进交付（2026-11-06）

本轮落实此前核对为成立的全部改进方向。对不成立的建议不机械照做：保留正确的 SQLite NULL 比较、交易防线与实际能力边界；兼容接口保留外观，但不再拥有独立执行状态机。

## 改进与证据

| 审查方向 | 已落地改动 | 关键验证 |
| --- | --- | --- |
| 交易文字与播报可信 | `factual_replies.py` 从真实工具结果或操作状态生成业务回复；未核实的模型业务措辞不流式展示。交易、订单进度和候选语音不再自由改写。普通聊天保留模型表达，正则仅作补充内容检查。 | “单子弄好了／师傅在路上”等绕过原正则的表达不会进入正文、播报或增量；确认卡仍包含真实金额与状态。 |
| 前端职责拆分 | `useChat` 消息 reducer、`useContact` 恢复与 SSE、`usePhone` 通话、`useComposer` 输入／图片、`useLocation` 定位；控制器只协调副作用。入口、应用视图、消息列表、单条消息、旧候选、输入区、图标分别成模块。旧方案统一使用 `ActionCard`。 | 既有语音插话、迟到回复、挂断、重试、卡片与支付交接测试保留；全量前端行为测试通过。 |
| 事件类型与边界 | 独立 `ContactEvent` 联合类型；未知 JSON 先做运行时校验，再进穷举 switch。校验嵌套方案、金额、图片、业务事件。去掉前端源码的 `any`。畸形历史记录单独跳过，不阻断其他记录。 | 畸形 SSE 不能添加卡片或打开付款页；重复完成事件只显示一次；有效历史仍可恢复。 |
| 模型可见数据白名单 | `model_views.py` 按服务、容器、子对象明确投影；未知字段逐层丢弃，允许的标量不能包藏对象。候选与历史方案使用专门视图，订单公开视图也改为正向字段选择。同步保留其他改动新接入的航班查询结果契约。 | 新增 accountToken、嵌套凭据、内部 request／quote／confirmation_token 均不进入模型；真实候选序号、公交站点和路线指引保留。 |
| prompt 与硬约束分离 | 策略放在 `app/policies/`，一般策略缩为身份、表达与事实边界；能力／模式／开关注入与实际注册表一致。预算、参数、确认和状态仍由宿主校验。普通资料写入新增“活跃用户轮次＋明确请求”检查。 | 闲聊没有业务工具；只读目录不声明写能力；模型不能在普通陈述或否定保存请求中擅自修改资料。 |
| 单一交易网关 | `PlanStore` 改成 `ActionManager` 兼容外观；旧 SQL 记录幂等导入，owner、id、未知结果与原始审计表保留。绑定统一网关后重新打开旧路径仍读同一数据。旧进程若迁移后又改记录，保守失效／转 unknown。新模型不再注册旧四个点餐工具，前端没有 `/api/plans/*` 执行代码。 | 原竞争认领、版本、令牌、过期、篡改、重核价、未知不重试测试继续通过；补充迁移、跨 owner、旧新方案互相失效、晚到旧写入测试。 |
| 金额统一 | 前一轮已统一整数分与前后端精确格式化，本轮保持此契约。 | 分位、极值与非法输入测试，以及现有费用明细和确认卡测试通过。 |
| 依赖与生命周期 | `create_app` 注入每个应用的 RuntimeServices；模块导入不建库或启动调度。lifespan 负责恢复／启停，请求上下文分隔不同应用。兼容命名导入仅是惰性代理。原实验未知请求保护保留。 | 双应用并发隔离、拒绝来源不初始化依赖、导入不实例化、启动恢复与关闭测试通过。测试用隔离工厂替代生产全局实例。 |
| MCP 解析复用 | 公共 `extract_payload` 只处理结构和唯一性；麦当劳、瑞幸、滴滴分别保留各自业务成功／拒绝判断。 | 结构化结果优先、重复／缺少 JSON 拒绝、不同业务封装、拒绝状态测试通过。 |
| 方案字段统一 | 内部及现代公开方案使用英文 snake_case 和 `summary_version=1`。旧中文／旧英文别名读取时归一化；旧 HTTP 兼容视图可附加旧字段，持久记录不被覆盖。中文标签由展示层提供。 | 新旧字段冲突时规范字段优先；旧客户端显示和现代存储分别验证。 |
| 队列 API 可读性 | `has_pending_any`、`has_pending_call` 替代魔数哨兵；保留有注释的 NULL 安全 SQL。 | 电话／聊天队列、合并、补充与重连相关测试通过。 |
| 启动供应链 | 前一轮已取消自动下载执行安装器，本轮保留已安装 uv 与锁文件流程。 | 临时目录启动参数、原配置保留及 shell 检查通过。没有代用户安装软件。 |
| README 用户可见性 | 首页围绕家属：价值、已有聊天截图、对话示例、交互示意、四步准备；详细配置与工程信息迁到 setup／架构／服务与验收文档。没有把未验收交易宣传为普遍可用。 | Markdown 链接、图像文件、构建首页与浏览器页面检查。截图注明来自已有隔离验收，不冒充当前真实交易凭证。 |

## 验证结果

- 后端全量自动化测试：**338 项通过**。
- 前端行为测试：**88 项通过**；TypeScript 与 Vite 生产构建通过。
- 浏览器使用独立 8014 临时数据服务：页面加载、输入、提交、SSE 更新与完整高德天气回复可见，未操作正式聊天或交易记录。
- 真实生产 HTTP 消息路径：聊天 2.774 秒、当前天气 2.721 秒、麦当劳门店查询 4.880 秒；本次小样本仅作观测。
- 真实麦当劳返回北京西站 5 家门店，均未营业。菜单请求未成功，因此**本轮没有完成真实核价确认卡的正向验收**。未营业时宿主不引导立即选店，卡片禁用不可用候选；没有绕过营业限制、伪造报价或执行外部交易。
- 未验证物理麦克风／扬声器、干净 Mac 安装，未新增订单、取消、付款、配送地址写入或出票。
