## 理念、规划与历史

- [产品理念](product-identity.md)：目标用户与理想体验，愿景不能当服务承诺。
- [路线图](roadmap.md)：当前阶段、主要缺口与下一步，不把已保存回执算作长期自主任务。
- [原始任务](original-task.md)：项目起点原文。
- [`acceptance/`](acceptance/)：带日期与范围的验收记录；测试数量按各自版本解释。
- [`research/`](research/)：历史第三方资料和接口快照，不是本产品运行依赖或功能清单。
- [`experiments/`](../experiments/)：人工联调脚本，先读行为再运行，不批量启动交易探针。

**文档维护规则：**能力变化更新首页和对应专题；状态变化更新路线图；每次可交付改进进入更新记录；验收只记录实际跑过的行为。真实Key、私人数据和未去敏日志留在忽略的本机目录，不进入公开文档。
