# 陪伴角色的状态与动作

角色使用现有三张透明 PNG、状态图标和 CSS 姿态变化，不是随机切换图片，也不是口型同步动画。

| 状态 | 实际触发条件 | 可见变化 |
|---|---|---|
| 空闲 | 没有录音、播报或待处理任务 | 缓慢轻呼吸，无状态图标 |
| 倾听 | 正在录音、连接或识别；通话空闲监听 | 身体侧向倾听，耳朵图标和轻微光圈 |
| 思考 | 正在处理普通请求或准备语音 | 身体轻微前倾、三个思考点依次变化 |
| 说话 | 音频实际开始播放 | 轻微说话姿态和变化的声波条 |
| 出行 | 实际处理进度为车型、行程等出行查询 | 拿小车的图片与车辆图标 |
| 餐饮 | 实际处理进度为门店、菜单、餐品、饮品或核价 | 拿餐袋的图片与餐饮图标 |

开着麦克风不代表角色一直只能倾听。实际播报和正在执行的任务可以切换角色；用户开始录音或进入识别时，及时转为倾听。音频仍在准备时只表示思考，不假装已经说话。

任务类型读取当前文字消息的处理进度或当前通话的处理进度，不使用上一条用户消息里的关键词。这样，“昨天打过车，今天只聊天”不会误触发打车形象。任务结束自然恢复；极短任务的形象总展示时间至少约 1.2 秒，避免一闪而过，新任务、倾听和播报可以立即打断这一过渡。

角色不再显示举牌文字或底部状态文案，处理进度仍只在对应消息或顶部通话岛中展示。桌面通话时保留侧边小人；窄屏继续隐藏侧边装饰，避免遮挡消息和输入框。系统启用减少动态时关闭动画，但保留姿态分类、图标和配色差异。头像仍是固定身份入口。

## 验证

本轮 68 项前端测试、TypeScript 与 Vite 构建通过。其中 9 项角色测试验证状态优先级、六种外观、真实消息／通话事件联动、旧关键词不误触发、任务结束恢复、延迟过渡取消及减少动态规则。生产预览仍需用户查看实际动效；自动化测试不能代替真人对动作辨识度的评价。
