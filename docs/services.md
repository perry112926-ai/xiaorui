# 生活服务使用说明

配置对应账号后，直接说要办的事。小瑞从官方服务取得门店、商品、地点和费用，把结果做成卡片。卡片可以点击，也可以在通话里报选项。餐品价格按菜单参考价或整单核价分别标示。

## 麦当劳

说「想吃麦当劳，三十块以内，送到家」。小瑞核对城市和收餐地址，查询可送门店、带图套餐和实际费用。也可以选择到店自取，或在同一家店增减餐品和数量。新配送地址需要单独核对城市、门牌、联系人和手机号，再确认写入麦当劳账号。

选好餐品后，核对商品、数量、地址、备注和总价。确认且重新核价通过后，麦当劳可返回待支付订单及官方入口。浏览器拦截新标签页时，从订单卡片点击「打开官方支付入口」。桌面端可按官方页面提示用手机扫码。

## 瑞幸

说「帮我找附近的瑞幸，我去店里拿」。核对门店、饮品、温度、糖度和数量后，小瑞展示官方核价和自取方案。查看进度时使用小瑞记录的本人订单。

## 滴滴

说「帮我从北京西站打车去国贸」。核对上车点、下车点，比较可选车型和估价。确认叫车时以方案展示的实际接送点和账号扣款规则为准。叫车后可查询本人订单与司机状态，取消前查看官方条件和费用。

## 确认、变更与取消

- 选中卡片后可以继续修改。确认卡显示具体操作及生效条件，金额或实质内容变化时重新确认。
- 价格过期时可在有效卡片上重新核价。换门店、换地点或切换任务后，旧确认方案随之失效。
- 外部请求结果未知时，先核查订单。已支付订单、费用未明的取消或售后问题可从官方订单入口办理。
- 停止播报或挂断只结束本地语音。放弃待确认方案与取消已经创建的订单分别操作。
- 三家订单开关默认关闭。只读演示、服务凭据及账号设置见[部署与配置](setup.md)。
